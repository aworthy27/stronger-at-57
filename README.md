# Stronger at 57

A simple iPhone-friendly Monday-Friday no-equipment workout PWA.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `stronger-at-57`.
2. Upload all four files from this folder to the repository root.
3. In the repository open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. After GitHub publishes it, open the Pages URL in Safari on your iPhone.
7. Tap **Share → Add to Home Screen → Add**.

Progress is stored locally in the browser on that device.
